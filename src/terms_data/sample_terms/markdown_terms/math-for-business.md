#### product-rule-derivatives
The product rule is used to find derivatives of products of functions.

:p Find the product of f(x) = (1-x) and g(x) = x^2 using calculus.
??x
To solve this problem, we can use the product rule of derivatives in calculus. The product rule states that if we have two functions, f(x) and g(x), their product h(x) = f(x)g(x) can be differentiated as:

h'(x) = f'(x)g(x) + f(x)g'(x)

In this case, our two functions are f(x) = (1-x) and g(x) = x^2. Therefore, their product h(x) = f(x)g(x) is:

h(x) = f(x)g(x) = (1-x) * x^2

Taking the derivative of h(x) with respect to x, we get:

h'(x) = f'(x)g(x) + f(x)g'(x)
= (-1) * x^2 + (1-x) * 2x
= x(2-3x)

#### quotient-rule-derivatives
The quotient rule is used to find derivatives of quotients of functions.

:p Find the derivative of f(x) = (3x^2 + 2x) / (x + 1) using calculus.
??x
To solve this problem, we can use the quotient rule of derivatives in calculus. The quotient rule states that if we have two functions, f(x) and g(x), their quotient h(x) = f(x) / g(x) can be differentiated as:

h'(x) = (f'(x)g(x) - f(x)g'(x)) / g(x)^2

In this case, our function is f(x) = (3x^2 + 2x) / (x + 1). To find its derivative, we need to apply the quotient rule.

Let's calculate the derivative step by step:

f'(x) = (d/dx)[(3x^2 + 2x) / (x + 1)]

Using the quotient rule:

f'(x) = [(2x(x + 1) - (3x^2 + 2x)(1)) / (x + 1)^2]

Simplifying further:

f'(x) = (2x^2 + 2x - 3x^2 - 2x) / (x + 1)^2
= (-x^2) / (x + 1)^2

Therefore, the derivative of f(x) = (3x^2 + 2x) / (x + 1) is f'(x) = (-x^2) / (x + 1)^2.
