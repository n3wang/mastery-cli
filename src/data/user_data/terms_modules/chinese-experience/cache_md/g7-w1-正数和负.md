In the introduction of this chapter, when expressing **temperature**, **production growth rate**, and **income and expenditure**, we need to use numbers such as **3, 1.8%, 3.5**, and also numbers such as **−3, −2.7%, −4.5, −1.2**.

Their actual meanings are respectively:

- **−3°C** → 3 degrees below zero
- **−2.7%** → a decrease of 2.7%
- **−4.5 yuan** → an expenditure of 4.5 yuan
- **−1.2 yuan** → a deficit of 1.2 yuan
    

In ancient China, people used **counting rods (算筹)** as a tool for calculation.  
**Red rods** represented **positive numbers**, and **black rods** represented **negative numbers**.

We know that numbers like **3, 1.8%, 3.5**, which are **greater than 0**, are called **positive numbers**.

Numbers like **−3, −2.7%, −4.5, −1.2**, which have the symbol **“−” (minus)** placed in front of a positive number, are called **negative numbers**.

Sometimes, in order to make the meaning clearer, we also place the symbol **“+” (plus)** in front of positive numbers.

For example:

```
+3, +2, +0.5, +1/3
```

are simply the same as
```

3, 2, 0.5, 1/3.
```

The **“+”** and **“−”** placed before a number are called the **sign of the number**.

**0 is neither a positive number nor a negative number.**

### 1 什么是正数

**大于 0 的数叫做正数。**

例如：
* 3
* 1.8%
* 3.5

这些数都 **大于 0**，所以它们都是 **正数**。
有时候我们也可以写成：

* +3
* +2
* +0.5
* +1/3

这里的 **“+” 叫做正号**，但通常可以省略，所以：
+3 = 3


### 2 什么是负数

如果在一个正数前面加上 **“－”号**，就表示 **负数**。

例如：
* −3
* −2.7%
* −4.5
* −1.2

这些数都表示 **比0小的量**。

---

### 3 负数在现实中的意义

负数通常表示 **相反的情况**。

| 数     | 实际意义   |
| ----- | ------ |
| −3°C  | 零下3度   |
| −2.7% | 减少2.7% |
| −4.5元 | 支出4.5元 |
| −1.2元 | 亏空1.2元 |

可以看到：

* **正数** → 增加、收入、向上
* **负数** → 减少、支出、向下

---

### 4符号（+ 和 −）

一个数前面的 **“+” 或 “−”** 叫做 **符号**。

例如：

* +5 → 正数
* −5 → 负数


---

### 历史小知识

中国古代用 **算筹**（一种计算工具）计算：

* **红色算筹 → 正数**
* **黑色算筹 → 负数**

说明中国很早就有 **正负数的概念**。

1. **正数**：大于0的数
2. **负数**：在数前加 “−” 的数
3. **符号**：+ 或 −
4. **0**：既不是正数，也不是负数，是分界点
