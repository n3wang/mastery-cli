#### What-Why-How-Example Format

Background context: The "what," "why," "how," example format ensures that all key points are covered in a structured manner, making it easier for the audience to understand and follow.

:p How can you structure your communication using the what-why-how-example format?

??x
Using the "what," "why," "how," example format helps organize your message effectively. Here’s how:

1. **What:** Clearly state what action or change is being proposed.
2. **Why:** Explain the reasons behind this decision or action.
3. **How:** Describe the steps you plan to take to achieve the goal.
4. **Example:** Provide a specific example of how this will work in practice.

For instance:
- **What we are seeking to do:** Implement a new customer feedback system.
- **Why it's important:** To better understand and address customer needs.
- **How we intend to proceed:** By integrating customer surveys into our existing CRM.
- **Example of your role and support:** As a consultant, you'll lead the development of survey questions.

```java
public class Example {
    public void structureCommunication() {
        // What
        System.out.println("Implementing a new customer feedback system.");
        
        // Why
        System.out.println("To better understand and address customer needs.");
        
        // How
        System.out.println("By integrating customer surveys into our existing CRM.");
        
        // Example of your role and support
        System.out.println("Lead the development of survey questions with full support from the team.");
    }
}
```
