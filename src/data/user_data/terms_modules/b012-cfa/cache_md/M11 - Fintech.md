Introduction to Fintech
Fintech refers to developments in technology that can be applied to the financial services industry.

Companies that are in the business of developing technologies for the finance industry are referred to as fintech companies.

Fintech includes:
- Functionality to handle large datasets from many sources and formats
- Tools and techniques (e.g., artificial intelligence)

Big Data refers to all the potentially useful information that is generated in the economy.

Traditional sources of data include financial markets, company financial reports, and government statistics.

Alternative (nontraditional) sources of data include social media posts, online reviews, email, and website visits.

Corporate exhaust: includes bank records and retail scanner data Internet of things: all devices with connections to the internet

Characteristics of Big Data
The characteristics of Big Data includes volume, velocity, and variety:
- Volume: grows by order of magnitude (megabytes to petabytes)
- Velocity: speed of communication (real-time data has low latency)
- Variety: the structure in which the data exists

Data exists in different forms and structures:
- Structured forms include spreadsheets and databases
- Semistructured forms include photos and web page code
- Unstructured forms include video

Data Science and Data Processing
Data science concerns how we extract information from Big Data. Data science describes methods for processing and visualizing data.

Data processing methods
- Capture: collecting data and transforming it into usable forms
- Curation: assuring data quality by adjusting for bad or missing data
- Storage: archiving and accessing data
- Search: examining stored data to find needed information
- Transfer. moving data from their source/storage to where needed

Visualization Techniques and Challenges
Visualization techniques include the familiar charts and graphs that display structured data.

Visualization of less structured data requires other methods (e.g., word clouds and mind maps).

Challenges of Big Data
- High-quality data is required
- Accounting for outliers, bad or missing data, sampling biases
- Processing and organizing volume data

Artificial Intelligence
Artificial intelligence simulates human cognition using computer programs and automation.

Neural networks are programmed to process information in a similar way to the human brain.

Machine learning is a computer algorithm designed to learn, detect, and recognize patterns in the input data:
- Training dataset in which the algorithm looks for relationships
- Validation dataset to test and analyze the predictive ability
- Requires vast amounts of data, any distribution, but a "black box"

Supervised and Unsupervised Learning
In supervised learning, the input and output data are clearly labeled. The machine learns to model the outputs from the inputs and is then tested on new data.

In unsupervised learning, the input and output data are not labeled. The machine learns to describe the structure of the data.

Deep learning uses layers of neural networks to identify simple and complex patterns within the data. This includes both supervised and unsupervised learning (e.g., image and speech recognition).
