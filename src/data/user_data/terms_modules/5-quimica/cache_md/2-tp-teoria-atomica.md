#### Composición centesimal – teoría general

Para calcular **composición centesimal** de una sustancia:
1. Se necesita la **fórmula molecular**.
2. Se buscan las **masas atómicas** de los elementos (tabla periódica aproximada):

   * H = 1 g/mol
   * C = 12 g/mol
   * O = 16 g/mol
   * N = 14 g/mol
   * S = 32 g/mol
   * Na = 23 g/mol
   * Ca = 40 g/mol
   * Al = 27 g/mol
   * P = 31 g/mol
3. Se calcula el **Mr total** sumando las masas.
4. Se calcula el porcentaje de cada elemento con la fórmula:

* Ácido sulfúrico ($H_2SO_4$)
* Hidróxido de sodio ($NaOH$)
* Nitrato de calcio ($Ca(NO_3)_2$)

:p Calcule la composición centesimal en masa de las sustancias:
??x
* $H_2SO_4$, Mr=98.1 g/mol → %H=2.06, %S=32.7, %O=65.3
* $NaOH$, Mr=40 g/mol → %Na=57.5, %O=40.0, %H=2.5
* $Ca(NO_3)_2$, Mr=164.1 g/mol → %Ca=24.4, %N=17.1, %O=58.5
x??
