#### Ejercicio de nomenclatura inorgánica

Para resolver, recordemos:

* **Ácidos oxoácidos**: se forman con no metales + oxígeno + H.
* **Hidruros**: elemento + hidrógeno.
* **Sales**: catión + anión (oxoaniones comunes: fosfatos, pirofosfatos, etc.).
* **Hidróxidos**: metal + OH⁻.
* **Óxidos**: combinación de un elemento con oxígeno.
* **Sulfuros**: metal + S²⁻.

#### Ácido piroarsénico — cómo deducir la fórmula

“Piro-” indica condensación de **dos oxoácidos** con pérdida de $$\mathrm{H_2O}$$. El ácido arsénico es $$\mathrm{H_3AsO_4}$$ (análog o a $$\mathrm{H_3PO_4}$$). Al dimerizar: se suman átomos y se resta agua: hidrógenos $$6-2=4$$, arsénicos $$2$$, oxígenos $$8-1=7$$. Resultado neutro.
:p Deduce la fórmula del **ácido piroarsénico** a partir de $$\mathrm{H_3AsO_4}$$.
??x
Pasos: $$2,\mathrm{H_3AsO_4}-\mathrm{H_2O}=\mathrm{H_4As_2O_7}$$. Comprobación: H: (6-2=4), As: (2), O: (8-1=7). ⇒ **$$\mathrm{H_4As_2O_7}$$**.
