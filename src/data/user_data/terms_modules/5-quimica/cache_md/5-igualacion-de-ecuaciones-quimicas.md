

#### Ejercicios de Reacciones Químicas (con estados de oxidación según la Tabla Periódica)

En la resolución de reacciones químicas es fundamental **asignar estados de oxidación (E.O.)** a cada elemento para identificar qué especies se oxidan y cuáles se reducen.  
La **Tabla Periódica** nos guía:

- **Metales de transición** (Fe, Cu, Mn, Cr) pueden tener varios E.O.
- **No metales** (O, Cl, S, P, I, N, C) suelen variar en oxidaciones según el compuesto.
- El **Oxígeno** casi siempre es -2, salvo en peróxidos (-1).
- El **Hidrógeno** es +1 (salvo en hidruros metálicos, -1).

#### Reacción 1 – Óxido de hierro con monóxido de carbono

Aquí intervienen el **hierro (Fe, grupo 8)**, el **oxígeno (O, grupo 16)** y el **carbono (C, grupo 14)**.  
Valores de oxidación:

- Fe: +3 → 0
- O: –2 (constante)
- C: +2 → +4

:p Balancea la reacción y señala qué elemento se oxida y cuál se reduce:  
$$\mathrm{Fe_2O_3 + CO \rightarrow Fe + CO_2}$$  
??x  
$\mathrm{Fe_2O_3 + 3CO \rightarrow 2Fe + 3CO_2}$

#### Reacción 2 – Permanganato con ácido clorhídrico

Participan **Mn (grupo 7)**, **Cl (grupo 17, halógeno)**, **K (grupo 1, metal alcalino)**, **O (grupo 16)** y **H (grupo 1)**.  
Valores de oxidación:

- Mn: +7 → +2
- Cl: –1 → 0
- K: +1
- O: –2
- H: +1

:p Escribe la reacción balanceada indicando los cambios de oxidación:  
$$\mathrm{KMnO_4 + HCl \rightarrow MnCl_2 + Cl_2 + H_2O + KCl}$$  
??x  
$\mathrm{2KMnO_4 + 16HCl \rightarrow 2MnCl_2 + 5Cl_2 + 8H_2O + 2KCl}$

#### Reacción 3 – Cobre con ácido nítrico

Elementos: **Cu (grupo 11)**, **N (grupo 15)**, **O (grupo 16)**, **H (grupo 1)**.

- Cu: 0 → +2

#### Reacción 6 – Combustión del etanol

Elementos: **C (grupo 14)**, **H (grupo 1)**, **O (grupo 16)**.  
Valores de oxidación:

- C: –2 / –3 → +4 (en CO₂)

- H: +1

$$\mathrm{C_2H_6O + O_2 \rightarrow CO_2 + H_2O}$$

$\mathrm{C_2H_5OH + 3O_2 \rightarrow 2CO_2 + 3H_2O}$
