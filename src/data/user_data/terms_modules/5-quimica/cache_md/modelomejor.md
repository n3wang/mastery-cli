#### Configuración electrónica y números cuánticos (Ejercicio 2)

Contexto:  
La configuración electrónica se determina siguiendo el principio de Aufbau (orden creciente de energía):  
$$  
1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p \dots  
$$  
Los números cuánticos describen la posición y energía del último electrón.

:p Para el elemento con $Z = 21$ (Escandio):

$$  
1s^2, 2s^2, 2p^6, 3s^2, 3p^6, 4s^2, 3d^1  
$$

B. Fósforo ($Z = 15$)  
Configuración electrónica:  
$$  
1s^2, 2s^2, 2p^6, 3s^2, 3p^3  
$$

Último electrón: en orbital $3p$.  
Números cuánticos:

- $n = 3$ (nivel principal)
    
- $l = 1$ (subnivel p)
    
- $m_l = -1, 0,$ o $+1$ (depende de cuál de los tres orbitales p ocupa, por convención se elige $m_l = -1$ para el primero)
    
- $m_s = +\tfrac{1}{2}$ (espín del electrón)
    

Por tanto, el conjunto típico es:  
$$  
n = 3,\ l = 1,\ m_l = -1,\ m_s = +\frac{1}{2}

#### Soluciones y mezclas gaseosas (Ejercicio 3)

Contexto:  
La solución fisiológica al 0.9% m/v significa 0.9 g de NaCl por cada 100 mL de solución.  
Densidad: $\rho = 1.005, \mathrm{g/mL}$  
Volumen: $V = 5,\mathrm{L} = 5000,\mathrm{mL}$

Fórmulas:

- Masa soluto: $$m_s = \frac{0.9,\mathrm{g}}{100,\mathrm{mL}} \times 5000,\mathrm{mL}$$
    
- Moles: $$n = \frac{m_s}{M_{NaCl}}$$
    
- Molaridad: $$M = \frac{n}{V_{solución,(L)}}$$
    
- % m/m: $$%m/m = \frac{m_{soluto}}{m_{solución}} \times 100$$
    

:p Calcular masa de NaCl, moles, molaridad y porcentaje m/m de una solución fisiológica 0.9% m/v, $5,L$, $\rho=1.005,g/mL$.  
??x

$$m_s = \frac{0.9}{100} \times 5000 = 45,\mathrm{g}$$

Paso 2. Moles de NaCl:  
$$n = \frac{45}{58.44} = 0.770,\mathrm{mol}$$

Paso 3. Molaridad:  
$$M = \frac{0.770}{5} = 0.154,\mathrm{mol/L}$$

Paso 4. % m/m:  
Masa de solución = $5000 \times 1.005 = 5025,\mathrm{g}$  
$$%m/m = \frac{45}{5025} \times 100 = 0.896%$$

#### Reacción entre CO y O₂ (Ejercicio 5)

Contexto:  
La reacción entre monóxido de carbono y oxígeno produce dióxido de carbono:  
$$2CO + O_2 \rightarrow 2CO_2$$

Si en el recipiente hay un número limitado de moléculas, el reactivo limitante es el que se consume primero.

Supongamos el gráfico muestra 4 moléculas de CO y 2 de O₂.

:p Dada la reacción entre monóxido de carbono y oxígeno, calcular (a) ecuación balanceada, (b) reactivo limitante, (c) moles y masa de CO₂ formados, (d) volumen del CO₂ a 780 Torr y 25°C, y (e) describir el esquema final.  
??x  
a) Ecuación balanceada:  
$$2CO + O_2 \rightarrow 2CO_2$$

b) Reactivo limitante:  
Si hay 4 CO y 2 O₂:

- Relación estequiométrica: 2 CO : 1 O₂
    
- Se necesitan 2 O₂ para reaccionar con 4 CO → reacción completa → no hay exceso.
    

c) Moles y masa de CO₂:  
Moles CO₂ formados = moles CO iniciales = 4 moléculas → 2 mol CO₂ por cada 2 mol CO.  
Si suponemos $n_{CO}=1,\mathrm{mol}$ → $n_{CO_2}=1,\mathrm{mol}$  
Masa CO₂ = $1\times44=44,\mathrm{g}$

$$V = \frac{nRT}{P}$$  
$$T = 25+273.15=298.15,K,\ P = 780,Torr = 1.026,atm,\ R = 0.0821$$  
$$V = \frac{1\times0.0821\times298.15}{1.026} = 23.85,L$$
